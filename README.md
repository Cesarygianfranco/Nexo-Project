# 🚀 Nexo - Inventory & Category Manager

**Nexo** is a modern and intuitive web application designed to manage categories and products efficiently. It focuses on delivering a clean user interface and a smooth user experience through a visually engaging card-based layout.

🔗 **Live Demo**: https://nexo-topaz.vercel.app/

---

## ✨ Features

### 📦 Category Management
- Full CRUD operations (Create, Read, Update, Delete)
- Custom image icons for each category
- Clean and organized card-based layout

### 🎨 Modern UI/UX
- Built with **Mantine UI**
- Smooth transitions and soft shadows
- Consistent and polished design system

### 🌗 Smart Theme Toggle
- Dark / Light mode switch
- Persistent theme preference
- Smooth rotation animation

### 🔍 Real-time Search
- Instant filtering by category name
- Optimized for fast user interaction

### 📱 Responsive Design
- Fully responsive across all devices
- Custom Burger menu and Drawer navigation for mobile

### 📄 Pagination
- Efficient data handling
- Prevents UI clutter and improves performance

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/Cesarygianfranco/Nexo-Project.git
cd Nexo-Project
```

### 2. Install dependencies

```bash
npm install
```

Make sure you have **Node.js** installed.

### 3. Run the development server

```bash
npm run dev
```

The app will be available at:
👉 http://localhost:5173
